# Dota AI Arbitrage — исследовательский сбор данных

Первый этап: сбор открытых профессиональных матчей Dota 2 через OpenDota, без ставок и без букмекерских аккаунтов.

## Как проверить
Открой **Actions → Collect Dota matches → Run workflow**. После завершения открой запуск и скачай артефакт `dota-match-snapshot` — JSON и CSV.

План: сопоставить драфты, результаты и временные показатели с синхронизированными котировками. Пока API коэффициентов не подключён, никаких утверждений о доходности вилок делать нельзя.

GitHub Actions запускается по расписанию независимо от компьютера. На публичном репозитории не размещай API-ключи или приватные данные.
